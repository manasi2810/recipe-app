🍲 Recipe App

A React recipe website built with TheMealDB API.

Features
Search recipes by name
Browse by category & cuisine
"What's in My Fridge" — find recipes by ingredient
Recipe detail page
Favorites ❤️ (localStorage)
Weekly Meal Planner 📅 (in progress, Firebase-backed)
Tech Stack

React · Vite · React Router · TheMealDB API · Firebase (Meal Planner)

Getting Started
bash
git clone https://github.com/manasi2810/recipe-app.git
cd recipe-app
npm install
npm run dev
